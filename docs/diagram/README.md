# homelab diagram

High-level architecture only.

`out/homelab.png` is generated by `build.py`. The diagram deliberately contains
**no** addresses, ports, hostnames, domains, VM IDs, hardware details, service
inventories, vhost lists or known gaps. Do not add live facts here.

The style is adapted from [Goblinmine/homelab-diagram](https://github.com/Goblinmine/homelab-diagram)
(MIT, see [LICENSE](LICENSE)).

## Render

Requires the Fira Sans and Fira Code fonts, and either `rsvg-convert`
(preferred) or ImageMagick with an SVG delegate.

```sh
cd docs/diagram
python3 build.py             # → out/homelab.svg + out/homelab.png
python3 build.py --optimize  # also compresses the PNG for the README
```

Do not hand-edit the PNG.
